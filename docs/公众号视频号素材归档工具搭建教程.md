# 从零搭建一个公众号视频号素材归档助手

这份文档记录了我们从一个电脑端开源项目出发，逐步做出 iPhone 可用 H5，再接入公众号直聊的完整过程。

工具当前只处理本人或已经获得授权的公开普通视频素材。它不是批量抓取工具，也不用于私密、付费、直播或受版权保护内容的传播。

## 1. 最终效果

用户侧只需要做三件事：

1. 在视频号里打开需要归档的素材，点击 `分享 -> 复制链接`。
2. 把链接发送给公众号。
3. 点击公众号回复的短链接，下载视频。

公众号回复的地址类似：

```text
https://saveclip.cn/d/xxxxxxxxxxxxxxxx
```

链接 10 分钟后失效。下载文件按下面的规则命名：

```text
作者_视频标题.mp4
```

如果保存到 iPhone 的“文件”App，文件名会保留。如果保存到“照片”App，iOS 通常不会展示原始文件名。

## 2. 最初的思路

一开始参考的是开源仓库：

```text
https://github.com/ltaoo/wx_channels_download
```

这个项目主要解决电脑端解析与下载。我们希望把使用场景搬到手机上，尤其是限制较多的 iPhone：

```text
视频号复制链接
-> 手机端入口
-> 解析
-> Safari 下载或保存到文件
```

最初讨论过四条入口路线：

1. iPhone 快捷指令，双击手机背面打开 H5。
2. 企业微信客服，用户扫码后向客服发送链接。
3. 小程序，解析后在小程序中下载。
4. 公众号直聊，用户在公众号对话框直接发送链接。

最后选择“公众号直聊 + H5 下载页”为主线，企业微信客服二维码保留为备用入口。原因很简单：公众号直聊的用户操作最少，不需要跳转客服会话。

## 3. 基础设施

### 3.1 服务器

使用一台腾讯云 Ubuntu 服务器。应用运行在 Node.js 上，由 systemd 管理：

```text
deployment/channels-archive.service
```

Node 服务监听：

```text
127.0.0.1:3100
```

Nginx 对外提供 HTTP 和 HTTPS：

```text
deployment/nginx.conf
```

### 3.2 域名与 HTTPS

注册域名：

```text
saveclip.cn
```

在 DNSPod 添加两条 A 记录：

```text
@    -> 服务器公网 IP
www  -> 服务器公网 IP
```

域名生效后，用 Certbot 为以下域名配置免费证书：

```text
saveclip.cn
www.saveclip.cn
```

Nginx 将 HTTP 自动跳转到 HTTPS。

验证地址：

```text
https://saveclip.cn/health
```

正常响应：

```json
{"ok":true}
```

## 4. H5 下载页

H5 首页位于：

```text
src/index.html
```

页面功能：

- 粘贴视频号分享链接。
- 确认素材属于本人或已获授权。
- 解析标题、作者和视频地址。
- 预览视频。
- 下载命名文件。
- 直接打开视频，作为 Safari 或微信内置浏览器受限时的兜底。

解析接口：

```text
POST /api/fetch_video_profile
```

下载接口：

```text
GET /api/download
GET /d/<ticket>
```

H5 页面使用签名下载地址。公众号使用更短的 `/d/<ticket>` 地址，避免微信将很长的查询参数截断。

## 5. 下载命名规则

命名逻辑位于：

```text
src/lib.js
```

规则：

```text
作者_标题.mp4
```

代码会移除文件系统不允许使用的字符，例如：

```text
< > : " / \ | ? *
```

文件名最长保留 150 个字符。标题为空时使用：

```text
视频号素材.mp4
```

服务端通过 `Content-Disposition` 将 UTF-8 文件名交给浏览器：

```http
Content-Disposition: attachment; filename="video.mp4"; filename*=UTF-8''...
```

## 6. 为什么公众号回复必须使用短链接

第一次打通公众号后，公众号可以正常解析并回复下载链接，但用户点击后立刻看到：

```text
下载链接已过期
```

实际并不是 10 分钟过期时间失效。原因是原始下载地址太长，包含：

- 视频 CDN URL
- 视频 token
- 作者
- 标题
- 过期时间
- HMAC 签名

微信在识别长链接时截断了后半段，`expires` 和 `sig` 丢失。服务端收到不完整 URL 后误判为过期。

解决方法是增加内存短票据：

```text
src/download-ticket.js
```

公众号只回复：

```text
https://saveclip.cn/d/<随机码>
```

服务器在内存中保存 10 分钟映射：

```text
随机码 -> 原始视频地址、作者、标题、过期时间
```

这样既避免微信截断，也不在聊天窗口暴露视频 CDN 地址。

注意：当前短票据保存在单机内存中。服务重启后，已经发出的短链接会失效。后续如果做多实例部署，应切换到 Redis。

## 7. 公众号直聊接入

公众号直聊是当前主入口。

用户体验：

```text
关注公众号
-> 在公众号对话框发送视频号链接
-> 公众号返回短下载链接
-> 点击下载
```

服务端代码：

```text
src/wechat-official.js
```

回调地址：

```text
https://saveclip.cn/api/wechat/callback
```

### 7.1 公众号后台设置路径

公众号旧后台已经迁移到微信开发者平台。进入：

```text
微信开发者平台
-> 公众号
-> 基础信息
-> 域名与消息推送配置
-> 消息推送
-> 启用
```

填写：

```text
URL: https://saveclip.cn/api/wechat/callback
Token: 从 .wechat-official.env 获取
EncodingAESKey: 从 .wechat-official.env 获取
消息加解密方式: 明文模式
```

`Token` 需要使用不超过 32 位的字母数字组合。我们第一次生成了 48 位 Token，后台提示“请输入正确的 Token”，缩短到 32 位后保存成功。

### 7.2 回调流程

启用消息推送时，微信会向回调地址发送 GET 请求：

```text
GET /api/wechat/callback
```

服务器校验签名后原样返回 `echostr`。

用户向公众号发送消息时，微信会发送 POST 请求：

```text
POST /api/wechat/callback
```

服务器处理过程：

1. 校验微信签名。
2. 读取 XML 文本消息。
3. 提取 `https://weixin.qq.com/sph/...` 分享链接。
4. 调用解析适配器。
5. 创建 10 分钟短票据。
6. 在 5 秒内用 XML 被动回复短链接。


企业微信客服接入过程中，我们验证了：

但当前主入口已经切换到公众号直聊。企业微信客服链路作为备用入口保留，不作为当前产品依赖。

```text

```

## 10. 当前解析层与商业边界

当前解析层仍然是内部学习交流版本。适配器位于：

```text
src/adapters/
```

正式对外运营前，需要切换到：

- 自研解析接口，或
- 已获得商业授权的解析服务。

现有 H5、公众号回调、短链接、文件命名和 HTTPS 架构可以保留。需要替换的是视频信息解析层。

正式运营前还需要增加：

- 单用户、单 IP 和全局限流。
- Redis 短票据存储。
- 用户授权记录。
- 日志脱敏。
- 隐私政策和服务条款。
- 投诉、下架和封禁机制。
- 监控和告警。

## 12. 排错顺序

遇到“公众号没有回复”时，按下面顺序排查：

1. `https://saveclip.cn/health` 是否正常。
2. 公众号后台消息推送是否启用。
3. URL、Token 和 AESKey 是否对应同一份配置。
4. Token 是否不超过 32 位。
5. Nginx 是否收到 `/api/wechat/callback` POST。
6. systemd 日志中是否有签名或 XML 解析错误。
7. 解析上游是否可用。

遇到“下载链接过期”时：

1. 检查公众号回复是否是 `/d/<ticket>` 短链接。
2. 确认链接是否超过 10 分钟。
3. 确认服务是否刚刚重启。
4. 检查 Nginx 是否收到完整短链接。
