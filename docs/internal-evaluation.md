# 内部学习交流版本

当前版本用于小范围内部学习、产品体验验证和 iPhone 操作链路测试。

## 当前链路

```text
iPhone H5
-> saveclip.cn 服务器
-> 临时公开上游 PROFILE_API_URL
-> 视频信息
-> iPhone 直接访问视频 CDN
```

服务器不保存视频文件。用户下载视频时，流量直接来自视频 CDN。

## 使用限制

- 仅处理本人或已获得授权的公开普通视频
- 仅支持单条分享短链
- 不用于公开收费服务
- 不支持批量抓取、搜索、私密内容、付费内容、直播或直播回放
- 不将真实 Cookie、Token 或密码写入 Git 仓库

## 后续商业版本

正式产品上线前，必须将 `PROFILE_API_URL` 替换为已获得商业授权的接口或自有合法数据源，并完成授权记录、短期任务链接、限流、日志脱敏和投诉下架机制。
