# 内部学习交流版本

当前版本用于小范围内部学习、产品体验验证和 iPhone 操作链路测试。

## 当前链路

```text
iPhone H5
-> saveclip.cn 服务器
-> 自建 Cloudflare 解析 Worker
-> 视频信息
-> iPhone 直接访问视频 CDN
```

服务器不保存视频文件。用户下载视频时，流量直接来自视频 CDN。

## 使用限制

- 仅处理本人或已获得授权的公开普通视频
- 仅支持单条分享短链
- 不用于公开收费服务
- 不支持批量抓取、搜索、私密内容、付费内容、直播或直播回放
- 不将真实 Cookie、Token 或密码写入 Git 仓库

## 2026-09-17 修复记录

原先借用的公开解析 Worker 新增了访问凭证校验，旧服务器因没有配置凭证而收到 `401`，机器人因此统一回复“暂时无法解析这个链接，请稍后重试”。

本次已部署自有 Cloudflare 解析 Worker，并将公众号机器人和 H5 的 `PROFILE_API_URL` 切换到该 Worker；真实访问凭证保存在服务器环境文件和 Cloudflare Secret 中。自建 Worker 同时移除了上游项目中已经过期的元宝请求头，改用当前登录态所需的请求头。

修复后已用视频号样例完成端到端接口验证，返回状态为 `200`，并获得可下载链接字段。
