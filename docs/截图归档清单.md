# 截图归档清单

聊天中使用过的后台截图没有自动保存到项目目录。为了避免把 Token、AESKey、身份证信息或密码带进仓库，建议只保留打码后的截图。

可以按下面顺序整理截图，并放到：

```text
docs/images/
```

## 建议保留

1. `01-dnspod-a-records.png`
   - DNSPod 中 `@` 和 `www` 的 A 记录。
   - 公网 IP 建议打码。

2. `02-saveclip-h5-mobile.png`
   - 手机端 H5 页面。
   - 展示粘贴链接、解析按钮和下载按钮。

3. `03-wecom-api-app.png`
   - 企业微信“可调用接口的应用”页面。
   - 展示自建应用已经接管客服账号。

4. `04-wecom-servicer.png`
   - 企业微信客服账号详情。
   - 展示接待人员已经由 API 配置。

5. `05-wechat-developer-platform.png`
   - 微信开发者平台公众号基础信息页面。
   - 展示“域名与消息推送配置”入口。

6. `06-wechat-message-push.png`
   - 公众号消息推送配置页面。
   - Token 和 EncodingAESKey 必须完全打码。

7. `07-official-account-chat.png`
   - 公众号对话框中发送视频号链接并收到 `/d/<ticket>` 短链接。
   - 用户昵称和 OpenID 等信息打码。

8. `08-iphone-download.png`
   - iPhone 下载命名文件后的效果。

## 已保留

artifacts/saveclip-wecom-contact-qr.png

## 不要保留

- 包含服务器密码的截图。
- 包含 AppSecret、Token、AESKey 或 Cookie 明文的截图。
- 包含身份证号码或个人实名信息的截图。
- 已经过期配置的复制粘贴记录。
